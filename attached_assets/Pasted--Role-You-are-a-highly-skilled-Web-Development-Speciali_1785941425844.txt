"**Role:** You are a highly skilled Web Development Specialist with expertise in implementing robust technical SEO and performance optimizations. Your task is to ensure that the website you are building, based on the provided scoping document, adheres to best practices for search engine visibility and delivers an exceptional user experience through fast loading times.

**Task:** Integrate the following technical SEO and speed optimization requirements into every aspect of the website build (HTML, CSS, JavaScript, and server-side configurations). These are fundamental, non-negotiable parts of the development process.

**1. Image Optimization & Delivery:**
    *   **Compression:** All images must be compressed without significant loss of quality. Utilize modern image formats like WebP where supported, with JPEG/PNG fallbacks for older browsers.
    *   **Responsive Images:** Implement responsive image techniques (e.g., `<picture>` element, `srcset` attribute) to serve appropriately sized images based on the user's device and viewport.
    *   **Lazy Loading:** Implement native lazy loading (`loading=""lazy""`) for all images and iframes that are not critical to the initial viewport (above-the-fold content). Ensure critical images are eagerly loaded.
    *   **Image Dimensions:** Specify explicit `width` and `height` attributes for all images to prevent layout shifts (CLS).

**2. Core Web Vitals (CWV) Optimization:**
    *   **Largest Contentful Paint (LCP):** Prioritize the loading of the largest content element in the viewport. This includes:
        *   Optimizing critical CSS (inline or preloaded).
        *   Preloading critical images or fonts.
        *   Minimizing server response time.
    *   **Cumulative Layout Shift (CLS):** Minimize unexpected layout shifts by:
        *   Reserving space for images and videos.
        *   Avoiding inserting content above existing content.
        *   Using CSS `transform` for animations instead of properties that trigger layout.
    *   **First Input Delay (FID) / Interaction to Next Paint (INP):** Optimize JavaScript execution to ensure quick responsiveness to user interactions. This includes:
        *   Minimizing main thread work.
        *   Breaking up long tasks.
        *   Deferring non-critical JavaScript.

**3. Code Optimization & Minification:**
    *   **HTML, CSS, JavaScript Minification:** Minify all HTML, CSS, and JavaScript files to reduce their file size.
    *   **CSS & JS Delivery:** Optimize CSS delivery (e.g., critical CSS, asynchronous loading for non-critical CSS) and defer non-critical JavaScript.
    *   **Remove Unused Code:** Eliminate any unused CSS or JavaScript from the final build.

**4. Structured Data Markup (Schema.org):**
    *   **Implementation:** Implement relevant Schema.org markup using JSON-LD for every page where applicable. This provides search engines with rich, structured information about the content.
    *   **Common Schemas (Home Service Focus):**
        *   **`LocalBusiness`:** For the main business information (name, address, phone, opening hours, reviews, services).
        *   **`Service`:** For each individual service offered by the client.
        *   **`FAQPage`:** For any FAQ sections on the site.
        *   **`Review` / `AggregateRating`:** For testimonials and overall business ratings.
        *   **`Organization`:** For the overall company information.
        *   **`WebPage`:** For general page types.
    *   **Validation:** Ensure all implemented schema markup is valid using Google's Rich Results Test tool.

**5. Meta Tags & On-Page SEO Fundamentals:**
    *   **Canonical Tags:** Implement canonical tags (`<link rel=""canonical"" href=""..."">`) on all pages to prevent duplicate content issues.
    *   **Language Declaration:** Ensure the `lang` attribute is correctly set in the `<html>` tag (e.g., `<html lang=""en"">`).
    *   **Robots Meta Tag:** Ensure appropriate `robots` meta tags are used (e.g., `index, follow` for pages to be indexed).
    *   **Open Graph & Twitter Cards:** Implement Open Graph (`og:`) and Twitter Card meta tags for optimal social media sharing previews.

**6. Server-Side Optimizations (if applicable to Replit environment):**
    *   **Caching:** Implement browser caching for static assets (images, CSS, JS) using appropriate HTTP headers.
    *   **GZIP Compression:** Ensure GZIP or Brotli compression is enabled for text-based assets.

**7. Accessibility (Recap & Integration):**
    *   Re-emphasize the importance of ADA compliance (WCAG 2.1 AA) as it directly impacts SEO and user experience. Ensure all previous ADA instructions are fully integrated.

**Global Application:**
These technical SEO and speed optimization requirements must be applied globally across the entire website, affecting all pages, components, and assets. Your goal is to deliver a website that ranks well, loads instantly, and provides an excellent experience for both users and search engines.
