---
name: Discovery form design scope
description: Verify redesigns through the CTA users actually click, not just a standalone route.
---

When asked to improve the discovery form, include the popup opened by the homepage CTA and verify that entry point directly.

**Why:** A standalone-page-only redesign twice left the user's actual form unchanged. The user was evaluating the popup, not the dedicated page.

**How to apply:** Check both presentation variants before scoping design work. Verify the default popup at normal desktop height with its submit button visible; never submit test leads.
